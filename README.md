# Native Americans: Tradition & Change (Englisch, Oberstufe)

Eine Lernumgebung für den Englischunterricht in der Oberstufe zum Thema Native Americans. Acht kurze englische Lesetexte behandeln Geschichte, Stereotype, historisches Trauma, Familie und Gemeinschaft, die Wiederbelebung von Kultur und Sprache, Landrechte und die Folgen der Kolonisierung. Jedes Kapitel hat ein Glossar und Aufgaben. Gedacht ist es für Expertengruppen: Jede Gruppe liest ihre Kapitel und erklärt sie danach den anderen.

**Direkt im Browser öffnen:** https://mrbraendt.github.io/eng-q-native-americans-oer/

Alles läuft in einer einzigen Datei `index.html`, ohne Anmeldung und ohne externe Dienste.
